TRÌNH PORTFOLIO — HOME V2

To update your existing GitHub Pages site:

1. Extract Trinh_Portfolio_Home_V2.zip.
2. Open your GitHub repository: portfolio.
3. Choose Add file > Upload files.
4. Upload these files to the repository root:
   - index.html
   - styles.css
   - script.js
   - vex.html
   - service.html
5. Also upload the assets folder so this path exists:
   assets/portrait-trinh.png
6. Commit changes.
7. GitHub Pages will redeploy automatically; no need to reconfigure Settings > Pages.

Important: index.html and styles.css must remain in the repository root.
