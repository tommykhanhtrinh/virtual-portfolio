GOOGLE SITES BUILD GUIDE — TRẦN NGUYỄN KHÁNH TRÌNH

Recommended pages
1. Home
2. VEX Robotics
3. Service Learning
Optional later: Engineering Projects / Leadership / Supporting Materials

Visual system
- White / very light gray base
- Deep navy for hero sections
- Electric blue + violet + mint accent blocks
- Use one large hero image per page
- Use rounded image crops and short captions
- Avoid putting the whole CV into paragraph blocks

Recommended Google Sites workflow
1. Open sites.google.com → Blank site.
2. Create the pages above in the Pages panel.
3. Use this prototype side-by-side as your visual reference.
4. Copy the text blocks from index.html, vex.html, and service.html.
5. Replace every placeholder with your real VEX / teaching / leadership photos.
6. Add buttons to supporting materials, GitHub, Engineering Notebook, competition videos, and official social pages when available.
7. Use image carousels only for event galleries; use single images for key storytelling moments.

Google Sites layout mapping
- Hero: Cover header + dark image/overlay
- Bento cards: 2- or 3-column section blocks with different background colors
- Metrics: 4-column text cards
- Timeline: stacked text + images vertically
- Gallery: image carousel or 3-column image section

Important content principle
Home = identity + strongest proof.
VEX = process, engineering depth, iteration, results.
Service Learning = people, teaching, leadership, impact.
Do not duplicate every award on every page.
