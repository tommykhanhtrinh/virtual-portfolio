ENGINEERING LOOP / 02

Design decisions needed evidence.

The biggest change from my first season was moving from “this should work” to “what does the test actually show?”

01 · CAD

Plan before assembly.

Using Onshape and a BOM made geometry, fit, mechanism placement, and drivetrain constraints visible before committing to the full build.

02 · TEST

Measure the mechanism.

Timing, consistency, jamming, pressure behavior, field interaction, and repeatability mattered more than a mechanism working once.

03 · CONTROL

Code cannot hide bad mechanics.

Autonomous accuracy depends on the physical robot too. Drivetrain alignment, wheel behavior, sensor placement, and mechanical consistency all shape localization and control.

04 · ITERATE

Each event became a design review.

Scrimmages, qualifiers, nationals, signature events, and Worlds gave us new evidence. Instead of preserving a robot because it was already built, I learned to treat rebuilds and version changes as part of competition engineering.

05 · DOCUMENT

Keep the robot history.

Why a mechanism changed matters. Documentation lets builders, programmers, strategists, and future versions share the same technical context.
